# Mira · Kit de marca

Revisió del 28 d’octubre de 2026. Identitat de Mira, sense cap nom d’aplicació afegit.

## Referència aprovada

L’arxiu `logos/Mira_original_aprovat.png` és la imatge aportada per l’usuari, conservada byte per byte. És la referència principal del disseny.

El signe combina la paraula Mira amb una M angular completa, amb la punta central descendent visible entre els dos ulls. Els ulls humans ambre se superposen a la M sense franges clares de parpella superior. Miren cap al cursor circular taronja situat damunt de la i, connectat visualment per la línia discontínua.

| Fitxer a logos/ | Ús |

| Mira_original_aprovat.png | Original sobre ivori, referència principal |
| Mira_color_transparent.png | Adaptació a color amb fons transparent; per a fons clars |
| Mira_negre_transparent.png | Adaptació monocroma negra amb fons transparent |
| Mira_color_text_blanc_fons_fosc.png | Lletres blanques, ulls ambre i cursor taronja sobre blau nit opac |
| Mira_monocrom_blanc_fons_fosc.png | Adaptació blanca sobre blau nit opac |

Les dues versions blanques tenen fons blau nit incorporat; no són PNG transparents. Les zones blanques de l’interior dels ulls en la versió a color es mantenen opaques. Els espais negatius de la monocroma negra deixen veure el suport.

Les variants són adaptacions raster generades a partir de l’original: poden presentar petites diferències de traç i no es garanteix una reproducció píxel a píxel. No s’inclouen originals vectorials, fonts tipogràfiques ni fitxers SVG. Per a una reproducció exacta del logo aprovat sobre ivori, utilitzeu l’original.

Aquests són valors de treball per compondre materials de marca, no una especificació colorimètrica de cada píxel. Els ulls, el cursor i el suavitzat dels PNG contenen matisos. La paleta també es lliura en JSON i CSS.

## Ús i proporcions

- Manteniu la relació d’aspecte de cada arxiu. Redimensioneu l’amplada i l’alçada de manera proporcional.
- Com a pauta de composició d’aquest kit, reserveu al voltant del conjunt un marge equivalent a un quart de l’alçada de la M. Incloeu el cursor dins de l’espai ocupat pel logo.
- Manteniu la posició i la direcció de la mirada dels ulls. No afegiu les franges clares de parpella eliminades.
- Eviteu situar el logo sobre fotografies o textures que en dificultin la lectura.
- Comproveu a mida real que es distingeixin els ulls, les ratlles i el cursor; no es fixa una mida mínima universal sense proves sobre el suport concret.
- Utilitzeu la versió negra sobre superfícies clares i les versions blanques sobre el blau nit lliurat.

La làmina mostra els PNG reals inclosos al paquet. No correspon a una nova proposta de logo.
